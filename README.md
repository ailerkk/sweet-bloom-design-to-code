# Sweet Bloom — Design-to-Code

## Project Overview

Sweet Bloom is a responsive landing page for a patisserie, created as part of the UI/UX Design-to-Code assignment.

**Author:** Yerlindik Ailen  
**University:** Narxoz University

## Project Objective

The objective is to explore how Figma design quality affects AI-generated code using Figma MCP and VS Code.

## Technologies

- Figma
- Figma MCP Server
- Visual Studio Code
- GitHub Copilot
- HTML5
- CSS3
- Git and GitHub

## Version 1

The initial website implementation generated from the original Figma design.

## Version 2

The second implementation generated from an improved Figma design with:

- Reusable components
- Component variants
- Color variables
- Typography styles
- Auto Layout
- Structured layer names
- Consistent spacing

## Comparison

| Criteria | Version 1 | Version 2 |
|---|---|---|
| Product card height | 432 px | 446 px |
| Button hover states | Limited | Improved |
| Image format | JPG | PNG |
| Design system | Initial | Improved |
| Responsive breakpoints | Available | Available |
| Code reusability | Limited | Limited |

## How to Run

1. Clone or download this repository.
2. Open the project in VS Code.
3. Open `version-1/index.html` or `version-2/index.html` in a browser.

## Conclusion

A structured Figma design improves the accuracy of generated code. Version 2 demonstrates better visual consistency and interaction states. However, manual review is still necessary to improve responsiveness, typography accuracy and code reusability.
